# Testpass – checklista

Kör tre riktiga pass med appen på iPhone och anteckna det som skaver. Skriv gärna direkt i
passets anteckning (⋯ → Anteckning för passet) så hamnar det i historiken.

## Före passet
- [ ] Appen öppnas från hemskärmen och visar senaste versionen (dra ner för att ladda om om inte).
- [ ] Rätt pass föreslås på startsidan (program aktivt) eller syns under "Vad kör du idag?".

## Under passet
- [ ] Ett tryck på **Klar** räcker för de flesta set – stämmer föreslagen vikt och reps?
- [ ] Snabbknapparna för vikt (±) räcker, eller saknas något steg?
- [ ] **Ångra** dyker upp och fungerar när du tryckt fel.
- [ ] Vilotimern: syns, hörs och vibrerar den? Även när skärmen släckts eller du bytt app?
- [ ] Byta/lägga till övning mitt i passet: hittar du övningen snabbt?
- [ ] Skärmen hålls tänd under passet.
- [ ] Testa minst en gång utan täckning (källare/flygplansläge) – allt sparas och synkas efteråt.

## Efter passet
- [ ] Sammanfattningen är begriplig och personbästan stämmer.
- [ ] Passet syns i Historik, även på en annan enhet efter en stund.
- [ ] Nästa pass i programmet är rätt.
